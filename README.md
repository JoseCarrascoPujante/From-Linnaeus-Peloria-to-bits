# EpiBit: cytosine-resolved information analysis of the Linaria vulgaris Peloria epiallele

Reference implementation and supporting data for De la Fuente et al., *From Linnaeus' Peloria to bits*.

EpiBit converts targeted bisulfite sequencing reads into cytosine-level Shannon entropy, directional Kullback-Leibler divergence, Jensen-Shannon divergence, mean bidirectional divergence and cumulative divergence-dimensionality, for the *Lcyc* locus of the Peloria epiallele of *Linaria vulgaris* and for the *LvHIRZ* control locus.

## Contents

| Path | Description |
| --- | --- |
| `EpiBit_code_package/epibit.py` | Reference implementation |
| `EpiBit_code_package/epibit_config_template.json` | Configuration template for `align` mode |
| `EpiBit_Supplementary_Data_Tables/` | Supplementary Tables S1-S8 and the two integrated cytosine-level workbooks |
| `FASTA_original/` | Raw targeted bisulfite FASTA files and the amplicon reference sequences |

# EpiBit reference implementation

## Language

Python 3.10 or later.

## Dependencies

```bash
python -m pip install numpy pandas openpyxl
```

`numpy` and `pandas` are required. `openpyxl` is needed to read the distributed Excel matrices and for Excel export in `from-matrix` mode.

## Analytical defaults used for the manuscript implementation

- `alpha = 0.5` pseudocount correction.
- `min_identity = 0.85` for read acceptance in the reference implementation.
- `min_overlap = 50` aligned bases in the reference implementation.
- Cytosines covered by at least one read in both conditions are retained; no further coverage threshold is applied. See *Coverage and site selection* below.

## Preparing the input matrices

The cytosine-level count matrices are distributed as Excel workbooks in `EpiBit_Supplementary_Data_Tables/`. Export the `Cytosine_matrix` sheet of each workbook to CSV before running `from-matrix`:

```python
import pandas as pd

for locus in ["Lcyc", "LvHIRZ"]:
    src = f"EpiBit_Supplementary_Data_Tables/{locus}_empirical_cytosine_methylation_matrix.xlsx"
    pd.read_excel(src, sheet_name="Cytosine_matrix").to_csv(f"{locus}_core.csv", index=False)
```

Supplementary Tables S7 and S8 contain the same counts, but their column headers are formatted for display and are not valid inputs to `epibit.py`.

The input matrix must contain:

```text
site_id, fragment, context,
WT_methylated_reads, WT_total_reads,
Peloria_methylated_reads, Peloria_total_reads
```

## Running from an already constructed cytosine-level matrix

```bash
python EpiBit_code_package/epibit.py from-matrix \
  --matrix Lcyc_core.csv \
  --outdir lcyc_epibit_results \
  --alpha 0.5
```

For LvHIRZ:

```bash
python EpiBit_code_package/epibit.py from-matrix \
  --matrix LvHIRZ_core.csv \
  --outdir lvhirz_epibit_results \
  --alpha 0.5
```

The distributed matrices already contain only the cytosines with non-zero read coverage, so `from-matrix` reproduces the manuscript values without any coverage argument. Running the two commands above reproduces Supplementary Tables S1 to S4 and the locus totals reported in the manuscript: for *Lcyc*, 98 cytosines, H_WT = 27.142 bits, H_Peloria = 45.111 bits, D_KL(Peloria||WT) = 87.421 bits, D_sym = 83.085 bits, JSD = 16.316 bits; for *LvHIRZ*, 29 cytosines and D_KL(Peloria||WT) = 0.934 bits.

## Running from raw bisulfite FASTA files

The four reference amplicon sequences are listed in `FASTA_original/NGS_Lvulgaris_Peloria_062026.docx`. Copy each into the `reference_sequence` field of `EpiBit_code_package/epibit_config_template.json`, one entry per locus and fragment, and save the result as `epibit_config.json`. The fragment-to-file mapping is:

| Fragment | Wild type | Peloria |
| --- | --- | --- |
| `LCYC_F3_R3` | `LCYC_FR_8.fasta` | `LCYC_FR_9.fasta` |
| `LCYC_peloria_fragment3` | `LCYC_fr3_8.fasta` | `LCYC_fr3_9.fasta` |
| `LCYC_peloria_fragment4` | `LCYC_fr4_8.fasta` | `LCYC_fr4_9.fasta` |
| `LvHIRZ_2` | `LvHIRZ_8.fasta` | `LvHIRZ_9.fasta` |

The suffix `8` denotes wild-type *Linaria vulgaris* and the suffix `9` denotes the Peloria mutant.

Example of a single locus entry:

```json
{
  "loci": [
    {
      "locus": "Lcyc",
      "fragment": "LCYC_F3_R3",
      "reference_sequence": "ACGT...",
      "samples": [
        {"condition": "WT", "fasta": "LCYC_FR_8.fasta", "allow_reverse_complement": true},
        {"condition": "Peloria", "fasta": "LCYC_FR_9.fasta", "allow_reverse_complement": true}
      ]
    }
  ]
}
```

Then run:

```bash
python EpiBit_code_package/epibit.py align \
  --config epibit_config.json \
  --outdir epibit_alignment_results \
  --min-identity 0.85 \
  --min-overlap 50 \
  --alpha 0.5 \
  --min-coverage 1
```

Alignment is an exhaustive offset scan implemented in pure Python. The complete dataset of 56,801 reads takes approximately one hour on a single core. `from-matrix` runs in under a second.

## Read alignment and acceptance rule

For each read, EpiBit evaluates direct and reverse-complement orientation against the corresponding reference amplicon. Placements are scored using a bisulfite-aware identity: at cytosines in the reference, both `C` and `T` in the read are treated as compatible with the reference, reflecting methylated and unmethylated bisulfite outcomes. At non-cytosine reference positions, exact base agreement is required. The orientation and offset with the highest sequence correspondence are retained. Reads are accepted if the best alignment identity is at least 0.85 and the aligned overlap is at least 50 bases. Accepted reads are then used for cytosine-level methylation counting; rejected reads are excluded.

For methylation calling at reference cytosines:

- read `C` = methylated observation;
- read `T` = unmethylated observation;
- other bases are ignored for that cytosine and recorded as `ignored_non_CT_at_C_sites`.

## Coverage and site selection

The 151 bp reads map to a single dominant offset per amplicon, so each reference amplicon is covered only in part: 98 of the 150 *Lcyc* cytosines and 29 of the 46 *LvHIRZ* cytosines receive reads. The manuscript analysis is restricted to these covered cytosines. No further coverage threshold is applied, and a site supported by a single read is retained.

In `align` mode the script annotates every reference cytosine, including uncovered ones. An uncovered site receives the pseudocount-only estimate p = q = 0.5, which contributes one bit of entropy to each condition and zero divergence. Reproducing the manuscript therefore requires `--min-coverage 1`. Without it, *Lcyc* yields 150 sites with H_WT = 79.142 bits and H_Peloria = 97.111 bits instead of 98 sites with 27.142 and 45.111 bits. The divergence totals are unaffected, because uncovered sites contribute zero divergence. Values of `--min-coverage` above 1 are sensitivity analyses.
